# وين نتبرع (Win Ntbara3) - خريطة نقاط التبرع وإغاثة متضرري الحرائق بالجزائر 🇩🇿🔥

منصة تفاعلية موجهة للتضامن الوطني وإغاثة المتضررين من حرائق الغابات في الجزائر. تتيح للمتطوعين والجمعيات والمواطنين تحديد ومشاركة نقاط جمع التبرعات والمساعدات، مع تمكين المتبرعين أو المحتاجين من العثور على أقرب مركز لهم والاتصال به مباشرة أو التوجه إليه عبر خرائط Google Maps.

## 🚀 المميزات الرئيسية:
1. **خريطة تفاعلية للجزائر**: تركيز دقيق على الولايات الـ 58 مع دعم خرائط متعددة (قمر صناعي، نمط ليلي، وخريطة واضحة).
2. **نقاط إغاثة حرائق عاجلة**: تمايز بصري بالوهج النابض للمراكز ذات الأولوية القصوى والاحتياجات الاستعجالية (أدوية حروق، مياه، أفرشة، عتاد إطفاء).
3. **تحديد الموقع الجغرافي بنقرة واحدة (GPS)**: للمتطوعين على الهاتف لإضافة موقعهم الحالي بدقة أو سحب الدبوس.
4. **رادار أقرب نقطة لي**: حساب المسافة بالكيلومترات وترتيب المراكز من الأقرب للأبعد مع فلاتر نوع المساعدة والولاية.
5. **بطاقة تفاعلية على طريقة Google Maps**:
   - زر اتصال هاتفي مباشر بالمنسق مع إظهار الرقم على الزر نفسه.
   - زر توجه وملاحة مباشر في تطبيق خرائط Google Maps.
   - مشاركة الموقع فورياً عبر WhatsApp.
6. **لوحة تحكم المشرفين (Admin Panel)**:
   - **قسم استيراد الروابط**: لصق أي رابط من Google Maps أو إحداثيات لاستخراج الموقع تلقائياً ونشره موثقاً.
   - إدارة النقاط، توثيقها، تفعيل الأولوية العاجلة، وحذف البلاغات غير الصالحة.
   - تصدير واستيراد قاعدة البيانات بصيغة JSON لسهولة النسخ الاحتياطي.
   - كلمة المرور الافتراضية: `admin123`.

## ☁️ النشر على Cloudflare Pages:
المشروع جاهز 100% للنشر الفوري على Cloudflare Pages بدون أي إعدادات معقدة:
- **Build command**: `npm run build`
- **Build output directory**: `dist`
- ملفات `_redirects` و `wrangler.toml` مهيأة مسبقاً.

## 💻 التشغيل المحلي:
```bash
npm install
npm run dev
```
